# Java Collections Framework — Complete Practice

A structured Java practice repository covering the **Java Collections Framework**, from fundamentals to practical examples of commonly used interfaces and implementations.

This project is part of my journey to strengthen my Core Java skills, problem-solving ability, and preparation for software development interviews.

## Topics Covered

### 1. Fundamentals
- Collections Framework overview
- Collection hierarchy
- `Collection` interface

### 2. List
- `ArrayList`
- `LinkedList`
- Common operations and element access
- Iteration and traversal

### 3. Set
- `Set` interface
- `HashSet`
- `LinkedHashSet`
- `TreeSet`
- `SortedSet`
- `NavigableSet`
- Adding, removing, searching, and iterating
- Array conversion and custom objects

### 4. Queue
- `Queue` interface
- `PriorityQueue`
- `ArrayDeque`
- `Deque` interface
- Queue operations and traversal
- Linked-list-based queue examples

### 5. Map
- `Map` interface
- `HashMap`
- `LinkedHashMap`
- `TreeMap`
- `Hashtable`
- Map traversal and utility methods
- Custom keys and advanced operations
